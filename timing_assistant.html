Timed Open Assistant

時刻補正つき URL オープン補助

このページは、サーバー時刻との差分を見積もって、指定時刻に URL を開くタイミングを補助するツールです。第三者サイトの購入や申込フローの自動操作は行いません。

できること

時刻補正、カウントダウン、複数回オープン、preconnect、実行状態の可視化。

実行場所

VSCode 上のローカルサーバーでも、同等の API を持つ Web 公開環境でも動かせます。

境界

URL を開く補助に限定します。他サイトの DOM 操作、巡回、自動購入は行いません。

1

実行条件

サーバー時刻との補正を使って、開くタイミングを調整します。

まずは時刻同期を行うか、そのまま待機を開始してください。
利用上の注意

このツールは指定 URL を設定した回数だけ開く補助機能を提供します。対象サイトの利用規約を確認し、許可される範囲で使用してください。

2

同期結果

最小遅延サンプルを採用します。
